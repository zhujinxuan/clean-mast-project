## 架构

```
cleanmast/
├── types/              # 核心类型定义和配置
├── parse_sensors/      # 数据解析和列映射
├── process/            # 数据清洗规则和验证
├── reconstruct/        # 数据重建模块
├── analyze/            # 风资源分析
├── reports/            # 报告生成
└── utils/              # 共享工具
```
