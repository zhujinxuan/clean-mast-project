# 气象测风塔传感器类型

> 本文档介绍气象测风塔常用的传感器类型及其规格，帮助用户理解 CleanMast 处理的数据来源和传感器解析逻辑。

## 概述

气象测风塔是风能资源评估的核心设备，用于采集风速、风向、温度、气压等气象参数。IEC 61400-12-1 标准对测风塔传感器的要求、安装位置和数据采集间隔做出了明确规定。CleanMast 通过 `SensorColumn` 类型解析各类传感器数据，支持风速、风向、温度和气压四种主要传感器类型的处理。

测风塔传感器的选型和安装直接影响数据质量。高质量的传感器配合正确的安装方式能够确保采集数据的准确性和代表性，为后续的风资源评估提供可靠的基础数据。传感器的测量精度、响应速度和环境适应性是评估其性能的关键指标。

## 风速传感器

风速传感器是测风塔上最重要的传感器类型，用于测量空气流动的速度。风能评估的准确性很大程度上取决于风速数据的质量。根据测量原理的不同，风速传感器主要分为机械式和超声波式两大类。

### 杯式风速计

杯式风速计是最传统的风速测量传感器，其工作原理基于机械转动。传感器由三个或四个半球形杯子安装在水平臂上组成，风力驱动杯子旋转，通过测量旋转速度换算成风速值。杯式风速计结构简单、成本较低且耐用性好，是测风塔上应用最广泛的传感器类型。

杯式风速计的主要技术指标包括启动风速、测量范围和距离常数。启动风速指传感器开始响应所需的最低风速，通常在 0.5 至 1.0 米每秒之间。测量范围覆盖从启动风速到极端风速，一般为 0 至 50 米每秒。距离常数描述传感器对风速变化的响应速度，距离常数越小，传感器的动态响应越好。IEC 61400-12-1 标准要求杯式风速计的距离常数应小于 5 米，以确保能够准确捕捉风速的脉动特性。

:llm-domain-write: 杯式风速计的精度等级分类及典型误差范围需专家确认。不同精度等级的传感器适用于不同的应用场景，校准证书上通常会标明传感器的精度等级和校准系数。

### 超声波风速计

超声波风速计采用超声波传播时间差原理测量风速。传感器在三个或四个方向上交替发射超声波，通过测量超声波在有风和无风条件下的传播时间差异计算风速向量。超声波风速计无需机械运动部件，具有更高的响应频率和更低的启动风速，能够测量三维风速分量和湍流特征。

超声波风速计的主要优势在于其优异的动态响应特性和多维测量能力。由于没有机械惯性，超声波风速计可以捕捉更高频率的风速变化，特别适合湍流强度和风速脉动的精确测量。同时，超声波风速计可以直接输出风的三维分量，避免了机械式传感器可能存在的方向性误差。超声波风速计的缺点是成本较高，且在极端低温环境下可能受到影响。

:llm-domain-write: 超声波风速计在结冰条件下的适用性和防护措施需专家确认。在寒冷地区使用时，可能需要配置加热装置或选择具有除冰能力的型号。

## 风向传感器

风向传感器用于测量风的来向，以度数或罗盘方向表示。风向数据对于风机偏航控制、尾流损失计算和扇区分析至关重要。风向传感器通常与风速传感器配合安装在同一个测量高度，以获取完整的矢量风特征。

### 风向标

风向标是最常用的风向测量传感器，由尾翼、指针和方位盘组成。风向标的尾翼在风力的作用下自动转向风的来向方向，指针指示相对于正北的方位角。风向标的启动风速通常低于风速传感器，以便在较低风速下也能准确指示风向。

风向标的性能指标包括阻尼比、尾翼尺寸和方位精度。阻尼比描述风向标的动态响应特性，适当的阻尼可以减少风向标的摆动幅度，提高测量稳定性。IEC 61400-12-1 标准对风向标的动态响应特性有具体要求，确保风向数据能够准确反映风的平均方向。风向标的安装方向需要精确校准，通常以正北为 0 度基准。

:llm-domain-write: 风向标的阻尼比测量方法和合格标准需专家确认。风向标的动态特性对风向数据的平滑处理有重要影响。

## 温湿度传感器

温度传感器用于测量空气温度，是计算空气密度和修正功率曲线的重要参数。空气密度与温度呈反比关系，准确测量温度有助于提高风功率密度计算的精度。测风塔上通常在多个高度安装温度传感器，以监测温度的垂直分布。

温度传感器的选型应考虑测量范围、精度和响应时间。典型的测风塔温度传感器测量范围为 -40 至 +60 摄氏度，分辨率达到 0.1 摄氏度。热电偶和热敏电阻是常用的温度测量元件。温度传感器应安装在防辐射罩内，避免太阳直射导致测量误差。防辐射罩通常采用多层结构设计，能够有效隔离太阳辐射热。

:llm-domain-write: 温度传感器的防辐射罩设计标准和安装要求需专家确认。防辐射罩的性能直接影响温度测量的准确性。

## 气压传感器

气压传感器用于测量大气压力，是计算空气密度的另一个关键参数。根据理想气体状态方程，空气密度与气压成正比。气压数据通常用于空气密度修正和气象条件分析。测风塔上的气压传感器一般安装在塔架底部或中部的防护箱内。

气压传感器的测量范围一般为 800 至 1100 百帕，分辨率达到 0.1 百帕。气压传感器对温度敏感，通常需要进行温度补偿。高精度气压传感器内置温度补偿电路，能够在不同环境温度下保持稳定的测量精度。

:llm-domain-write: 气压传感器的安装高度订正方法需专家确认。不同安装高度的气压测量值需要进行高度订正，以获取统一参考面的气压数据。

## 传感器安装要求

### 安装位置

传感器的安装位置直接影响测量数据的代表性和准确性。根据 IEC 61400-12-1 标准，测风塔上的传感器应安装在不受塔架本身干扰的位置。风速和风向传感器的安装应确保距塔架的水平距离至少为塔架直径的三倍，以减少塔架尾流的影响。

传感器安装应避开可能产生气流干扰的物体，如拉线、支架和其他设备。对于拉线式测风塔，传感器应安装在拉线结点的外侧，避免拉线引起的湍流。传感器的安装臂应坚固可靠，能够在强风条件下保持稳定的方向和姿态。

### 高度配置

测风塔的传感器高度配置应根据风资源评估的需求和塔架高度确定。典型的多高度测风塔配置包括 10 米、40 米、60 米、80 米和 100 米等多个测量高度。不同高度的传感器配置用于分析风切变特征和估算轮毂高度的风资源条件。

CleanMast 在处理多高度数据时，需要准确识别各传感器对应的测量高度。传感器高度信息应在配置文件中明确定义，包括各列数据所属的传感器高度和类型。高度配置错误会导致风切变分析和数据重建出现系统性偏差。

:llm-domain-write: 不同地形条件下传感器高度配置的最佳实践需专家确认。复杂地形可能需要更密集的测量高度配置以捕捉垂直风廊线特征。

## 与 CleanMast 的关联

CleanMast 通过传感器解析模块处理各类测风塔传感器数据。`SensorColumn` 类型定义了传感器的关键属性，包括传感器类型、测量高度、统计类型和数据列名称。CleanMast 支持以下传感器类型的解析和处理：

| 传感器类型 | CleanMast 类型标识 | 典型用途 |
|-----------|-------------------|---------|
| 风速传感器 | `WindSpeed` | 风资源评估、功率曲线验证 |
| 风向传感器 | `WindDirection` | 扇区分析、偏航优化 |
| 温度传感器 | `Temperature` | 空气密度修正 |
| 气压传感器 | `Pressure` | 空气密度修正 |

CleanMast 的数据解析功能能够识别各种数据格式的传感器列名，并根据配置文件将原始列名映射到标准化的传感器类型。数据清理阶段会对各传感器类型的数值进行范围验证，检测异常值和可能的传感器故障。传感器安装高度信息用于多高度数据的分析和重建处理。
