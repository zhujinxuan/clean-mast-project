# TowerShading 组件接口文档

## 概述

TowerShading 模块负责检测和校正测风塔对传感器的塔影效应影响。当风向指向塔架方向时，塔身会遮挡气流，导致下游传感器测量值偏低。该模块识别这些塔影区间并进行校正处理。

## 职责

- 检测受塔影影响的数据区间
- 对塔影期间的传感器数据进行校正
- 批量处理多个测风塔的塔影校正
- 输出校正后的时间序列数据

## 输入

- 时间序列数据：来自 DataClean 处理后的数据文件
- 塔影配置：tower-shading.toml 配置文件，包含测风塔列表及其输入输出路径

## 输出

- 校正后的时间序列数据：Parquet 格式
- 更新后的传感器描述文件

## 依赖关系

- 前置依赖：DataClean → ReconstructSingleMast
