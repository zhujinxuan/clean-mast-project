# ReconstructMeso 组件

## 概述

ReconstructMeso 负责使用训练好的中尺度模型重构测风塔缺失数据。该组件将中尺度数据（如 ERA5、freemeso）与测风塔数据进行融合，根据训练好的模型对缺失时间段进行填补。通过对齐时间戳、插值处理和来源追踪，实现测风塔数据与中尺度数据的一致性整合。

## 职责

- 加载 reconstruct-meso.toml 配置文件
- 加载所有中尺度数据源时间序列
- 加载经过 TrainMeso 训练的风速和风向模型（JLD2 格式）
- 对每个测风塔处理配置：加载测风塔时间序列数据
- 对齐测风塔与中尺度数据的时间戳
- 使用风速模型重构缺失的风速数据
- 使用风向模型重构缺失的风向数据
- 保存重构后的时间序列数据
- 输出重构来源追踪文件，记录每个重构点的模型来源

## 输入

- **reconstruct-meso.toml**: 重构配置文件，定义测风塔配置、中尺度数据源、模型文件路径、时间范围
- **测风塔时间序列数据**: 经过清理处理的时间序列文件
- **中尺度时间序列数据**: ERA5 或 freemeso 等中尺度数据源的时间序列文件
- **JLD2 模型文件**: TrainMeso 输出的训练模型，包含风速分段回归模型和风向偏移模型

## 输出

- **重构后的测风塔时间序列数据**: 将中尺度重构数据与原测风塔数据合并的时间序列
- **重构来源追踪 CSV**: 记录每个重构点的来源信息（重构时间戳、使用的模型 ID）
- **处理统计信息**: 控制台输出的重构统计（各模型重构点数统计）

## 依赖关系

```
TrainMeso → ReconstructMeso → RepresentativeYear
```

依赖 TrainMeso 模块提供的训练模型作为输入，输出重构后的数据供 RepresentativeYear 模块进行长年校准。
