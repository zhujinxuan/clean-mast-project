# TrainMeso 组件

## 概述

TrainMeso 负责训练将中尺度数据（如 ERA5、freemeso）与测风塔数据进行关联的统计模型。通过建立测风塔与中尺度数据源之间的对应关系，为后续的中尺度数据重构提供模型支持。该组件支持风速的分段回归模型训练和风向的偏移模型训练。

## 职责

- 加载测风塔时间序列数据和中尺度时间序列数据
- 对齐和预处理训练数据，确保时间戳匹配
- 训练风速分段回归模型（支持 16 方向扇区和单一扇区模式）
- 训练风向偏移模型
- 并行处理多个测风塔-中尺度数据对的模型训练
- 保存训练好的模型文件（JLD2 格式）
- 计算并输出训练结果指标（相关性系数等）

## 输入

- **train-meso.toml**: 训练配置文件，定义测风塔数据源、中尺度数据源、模型配置
- **测风塔时间序列数据**: 经过清理处理的时间序列文件
- **中尺度数据**: ERA5 或 freemeso 等中尺度数据源的时间序列文件

## 输出

- **JLD2 模型文件**: 按风速和风向分类保存的训练模型
- **train-meso-results.toml**: 训练结果指标文件，包含各数据对的相关性指标

## 依赖关系

```
DataClean → TrainMeso → ReconstructMeso
```

依赖 DataClean 模块提供的清理后数据作为输入，输出模型供 ReconstructMeso 模块使用。
