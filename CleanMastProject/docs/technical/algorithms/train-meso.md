# 中尺度模型训练算法

## 概述

中尺度模型训练算法用于建立测风塔观测数据与中尺度再分析数据之间的统计关联。该训练过程是后续中尺度数据重构的基础，通过分析两种数据源在重叠时间段内的对应关系，构建能够将中尺度数据转换为测风塔等效数据的转换模型。这些模型使得利用长时间序列的中尺度数据进行测风塔数据的长期重构成为可能，特别适用于风能资源评估中对代表性年的分析和长期风况特征的获取。

## 实现细节

### 训练算法步骤

训练过程遵循以下具体步骤：

1. **数据准备与对齐**：检测测风塔数据的时间间隔，确保数据规则化；将中尺度数据插值到与测风塔相同的时间戳
2. **传感器配对**：为每个测风塔风速传感器找到最近高度的中尺度风速传感器，找到最高高度的中尺度风向传感器
3. **数据清洗**：移除缺失值行，移除风速为0或负值的行
4. **分扇区训练**：根据风向将数据分组到各扇区，在每个扇区内进行线性回归

### 扇区模式

系统支持两种扇区模式：

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| `16-sector` | 使用16个风向扇区分别建模 | 风向对转换关系影响明显的复杂地形 |
| `1-sector` | 使用单一全局模型 | 数据量有限或风向影响不显著 |

#### 16扇区定义

风向被划分为16个等宽扇区，每个扇区覆盖22.5度的风向范围。这种划分基于传统气象16风向方位体系，能够有效区分不同风向条件下的风速转换关系。

每个扇区包含三个属性：
- **扇区名称**：采用标准气象方位名称（N、NNE、NE、ENE、E、ESE、SE、SSE、S、SSW、SW、WSW、W、WNW、NW、NNW）
- **中心角度**：扇区的中心风向值（0-360度）
- **扇区宽度**：每个扇区的角度范围（22.5度）

例如，北风扇区（N）的中心角度为0度，覆盖范围为348.75度至11.25度（0° ± 11.25°）。东北风扇区（NE）的中心角度为45度，覆盖范围为33.75度至56.25度，以此类推。

### 回归方法

#### 风速模型：分段线性回归

对于每个扇区，使用普通最小二乘法（OLS）进行线性回归：

```
mast_speed = slope × meso_speed + intercept
```

回归系数计算：
- 使用 `GLM.jl` 的 `lm(@formula(mast_speed ~ meso_speed), data)` 函数
- 扇区数据点 < 5时，使用全局回归系数作为后备

#### 风向模型：恒定偏移

计算中尺度风向与测风塔风向之间的平均角度差：

```
offset = mean(degree_diff(mast_direction, meso_direction))
```

其中 `degree_diff` 函数返回两个角度之间的最小差值（范围[-180, 180)度）。

### 数据质量阈值

| 条件 | 阈值 | 处理方式 |
|------|------|----------|
| 配对数据总量 | ≥ 10条 | 否则返回 `nothing`（训练失败） |
| 单扇区数据量 | ≥ 5条 | 使用扇区特定回归系数 |
| 单扇区数据量 | < 5条 | 使用全局回归系数作为后备 |
| 风速有效值 | > 0 | 过滤掉0和负值 |

### 模型结构

#### SectorizedRegressionModel（风速）

风速模型采用分扇区回归结构，将中尺度风速转换为测风塔等效风速。模型包含三个核心概念组件：

**整体模型结构（SectorizedRegressionModel）**：
- **pairs**：传感器配对列表，每个配对关联一个测风塔风速传感器与一个中尺度风速传感器
- **sectors**：使用的风向扇区定义（16扇区或1扇区）

**传感器配对（SpeedPair）**：
- **mast_speed_sensor**：测风塔风速传感器的列标识
- **meso_speed_sensor**：中尺度风速传感器的列标识
- **meso_direction_sensor**：中尺度风向传感器的列标识（用于判定数据所属扇区）
- **sectors**：该配对在各风向扇区内的回归系数集合

**扇区回归参数（SpeedSector）**：
- **direction_sector**：该组回归参数对应的风向扇区定义
- **slope**：回归斜率系数（k值），表示中尺度风速与测风塔风速的比例关系
- **intercept**：回归截距系数（b值），用于校正系统偏差

#### DirectionOffsetModel（风向）

风向模型采用恒定偏移结构，建立中尺度风向与测风塔风向之间的角度转换关系。模型包含两个核心概念组件：

**整体模型结构（DirectionOffsetModel）**：
- **pairs**：传感器配对列表，每个配对关联一个测风塔风向传感器与一个中尺度风向传感器

**传感器配对（DirectionPair）**：
- **mast_sensor**：测风塔风向传感器的列标识
- **meso_sensor**：中尺度风向传感器的列标识
- **offset**：角度偏移值（度），表示中尺度风向需要校正的角度差值

### 模型输出

训练完成后，模型以JLD2格式保存，文件结构如下：

```
{output_path}/
├── windspeed/
│   ├── 16-sector.jld2
│   └── 1-sector.jld2
└── winddirection/
    └── constant-offset.jld2
```

## 核心概念

### 数据源对应关系

中尺度数据来源于数值天气预报模型的再分析产品，如欧洲中心的ERA5、美国宇航局的MERRA-2等。这些数据覆盖全球范围、时间跨度长（通常可追溯至1979年或更早），但空间分辨率较低（0.25°至0.5°量级），代表的是网格平均的大气状态。测风塔数据则是地面或近地面点位置的精确观测，具有高时间分辨率（10分钟）和高空间精度，但观测时长有限（通常为1至5年）。训练算法的核心任务是建立这两种不同来源、不同尺度数据之间的定量转换关系。

### 训练与推理分离

训练算法遵循机器学习中经典的训练-推理分离范式。在训练阶段，系统利用测风塔与中尺度数据同时存在的重叠时间段，分析两者的统计特性并估计转换模型的参数。训练完成后，模型参数被保存至文件，可在后续任意时间应用于任意时长中尺度数据的转换。这种分离设计使得一次训练可以支持长期数据的高效重构，避免重复计算，同时保证历史重构结果的可重现性。

## 基本原理

### 相关性假设

训练算法建立在中尺度数据与测风塔观测之间存在稳定统计相关性的假设之上。尽管中尺度网格数据与测风塔点观测之间存在尺度差异，但两者所反映的大尺度大气环流背景是相同的。在足够长的训练周期内，通过适当的预处理（如时间对齐、空间插值、高度校正），可以提取出这种共同信号并量化其与局地测风塔观测之间的转换关系。相关性越强，训练得到的模型质量越高，后续重构结果也越可靠。

### 分变量建模

训练算法针对风速和风向分别建立独立的转换模型。风速模型关注的是中尺度风速与测风塔风速之间的数量关系，受大气稳定性地形效应等因素影响，不同风向对应的转换系数可能存在差异。风向模型关注的是中尺度风向与测风塔风向之间的角度偏移关系，主要反映中尺度网格平均与点观测之间的方向差异。这两类模型的结构和训练方式有所不同，但都遵循相同的训练范式：分析重叠期数据、估计模型参数、评估模型质量。

## 应用场景

### 长期数据重构准备

当项目需要获取长于测风塔实际观测年限的风况数据时，中尺度数据是唯一可用的长期数据源。但在直接使用中尺度数据之前，必须通过训练算法建立可靠的转换模型。典型的应用场景包括：评估风电场区域30年以上的风能资源特征、生成用于工程设计的极端风气候参数、分析风况的长期变化趋势等。只有经过训练的中尺度模型才能将这些长期中尺度数据转换为具有测风塔等效代表性的时间序列。

### 多数据源融合

当项目中同时存在测风塔观测和多种中尺度数据源时，训练算法可以帮助评估不同中尺度产品的适用性。通过对同一测风塔分别训练多个中尺度产品的转换模型，并比较各模型的训练质量（如相关性水平），可以识别出与本地观测吻合最好的中尺度数据源。这种评估对于选择最可靠的中尺度数据用于后续重构具有重要指导意义，特别是在复杂地形或海岸线附近等中尺度模型表现差异较大的区域。

## 输入数据

### 测风塔时间序列

训练算法的首要输入是经过前序处理阶段清洗和校正后的测风塔时间序列数据。这些数据应已完成以下处理步骤：传感器列映射和解析、数据范围验证、异常值处理、塔影效应校正等。测风塔数据的时间分辨率通常为10分钟，包含多个高度层的风速和风向测量值。训练算法会自动选择合适高度层的传感器进行建模，一般优先选择最高层的平均风速传感器以减少地表摩擦的影响。

### 中尺度时间序列

另一关键输入是中尺度再分析数据的时间序列，需要在parse-sensors配置阶段完成数据解析和格式转换。中尺度数据的时间分辨率通常为1小时，需要通过插值调整到与测风塔相同的时间基准。系统支持同时配置多个中尺度数据源（如ERA5和MERRA-2），训练算法会分别为每个数据源建立独立的转换模型。不同中尺度产品的网格分辨率、时空覆盖范围可能有所不同，训练过程会自动处理这些差异。

### 训练配置

训练行为由train-meso.toml配置文件控制。该文件指定参与训练的测风塔列表和中尺度数据源列表，以及每个模型组合的训练方法类型。配置中需要明确指定每个模型的输出路径，用于保存训练得到的模型参数文件。推荐使用recommend train-meso命令自动生成该配置文件，系统会根据项目现有的parse-sensors.toml和tower-shading.toml自动推断合适的输入数据路径和模型组合。

## 输出结果

### 训练模型文件

训练算法的主要输出是保存的模型参数文件，采用JLD2格式存储。每个模型文件包含完整的模型结构定义和估计得到的参数值，可被后续的reconstruct-meso阶段加载并应用于任意中尺度数据的转换。输出文件按照测风塔名称、中尺度数据源名称、变量类型（风速或风向）、训练方法类型的层次结构组织，确保多个数据源和多个模型组合的结果清晰可辨、不相互混淆。

### 训练质量报告

除模型文件外，训练算法还会生成train-meso-results.toml质量报告文件，记录每个模型在训练期的拟合质量指标。对于风速模型，报告会包含1-sector方法的训练相关性系数，反映中尺度与测风塔风速在整个训练期的整体对应关系。该报告可用于评估模型质量、判断训练是否成功、比较不同数据源的适用性等目的。建议在进入重构阶段前检查此报告，确保所有模型的训练质量达到可接受水平。

## 处理流程

### 数据准备与对齐

训练流程的第一步是准备和对齐输入数据。由于测风塔和中尺度数据的原始时间分辨率可能不同（通常为10分钟对1小时），系统需要先确定时间基准。推荐的做法是以测风塔的时间间隔为基准，将中尺度数据插值到相同的时刻。这一步骤还包括检测和标记两套数据的重叠时间段，确保后续训练仅使用两者同时有效的数据点。数据对齐的质量直接影响训练结果，应在训练前检查时间覆盖的完整性。

### 模型训练执行

数据准备完成后，系统按照配置文件中指定的模型组合依次训练各个模型。风速模型支持两种训练方法：16-sector方法将风速按照风向分为16个方向扇区分别建模，适合捕捉风向相关的转换关系变化；1-sector方法使用单一全局模型，适合数据量有限或风向影响不显著的情况。风向模型采用constant-offset方法，估计中尺度风向与测风塔风向之间的恒定角度偏移。训练过程在后台并行执行以提高效率，同时记录详细的日志信息用于问题诊断。

## 质量评估因素

### 重叠期覆盖度

训练质量的首要影响因素是测风塔与中尺度数据重叠时间段的覆盖程度。足够的重叠期应涵盖完整的季节变化循环，使模型能够学习不同季节大气状态的差异对转换关系的影响。经验上，建议至少使用6个月以上的重叠期数据，对于追求高精度的项目，12个月或更长的重叠期更为理想。如果重叠期过短，训练得到的模型可能无法充分反映真实的转换关系，导致后续重构结果的代表性不足。

### 原始数据质量

训练所依据的原始数据质量直接决定模型的质量上限。即使重叠期足够长，如果测风塔数据本身存在大量缺失或中尺度数据在目标区域存在系统性偏差，训练结果也会受到影响。系统默认使用tower-shading阶段的输出作为训练输入，正是因为该阶段的输出已经过塔影校正，具有更高的数据质量。如果tower-shading的有效数据不足150天，系统会自动降级使用reconstruct-cross阶段的输出作为替代。

### 相关性水平

训练完成后的相关性系数是衡量模型质量的关键指标。相关性越高，说明中尺度数据与测风塔观测之间的统计关联越强，模型能够解释的变异性越多。一般而言，1-sector风速模型的相关性应达到0.7以上才认为训练成功。如果相关性显著低于此阈值，可能的原因包括：中尺度数据与测风塔位置的空间不匹配、目标区域存在复杂地形导致中尺度模型表现较差、训练期数据存在未被标记的异常等。

## 配置示例

以下是train-meso.toml配置文件的完整示例：

```toml
[masts]
name = "PN01"
input = "data/processed/pn01/tower-shading"

[mesos]
name = "ERA5"
input = "data/processed/meso/era5"

[[models]]
mast_name = "PN01"
meso_name = "ERA5"
method = "16-sector"
output = "meso-models/pn01-era5/windspeed/16-sector.jld2"

[[models]]
mast_name = "PN01"
meso_name = "ERA5"
method = "1-sector"
output = "meso-models/pn01-era5/windspeed/1-sector.jld2"

[[models]]
mast_name = "PN01"
meso_name = "ERA5"
method = "constant-offset"
output = "meso-models/pn01-era5/winddirection/constant-offset.jld2"
```

## 默认推荐值

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 扇区模式 | `16-sector` | 风速模型默认使用16扇区分段回归 |
| 风向方法 | `constant-offset` | 风向模型默认使用恒定偏移方法 |
| 最小配对数据量 | 10条 | 全局训练所需的最少数据点 |
| 扇区最小数据量 | 5条 | 使用扇区特定系数的最少数据点 |
| 风速有效阈值 | > 0 m/s | 训练时过滤无效风速值 |
| 相关性阈值 | 0.7 | 训练成功的最低相关性要求 |
| 最小重叠期建议 | 6个月 | 推荐的最少训练数据时长 |
| 理想重叠期建议 | 12个月 | 高精度项目推荐训练时长 |
