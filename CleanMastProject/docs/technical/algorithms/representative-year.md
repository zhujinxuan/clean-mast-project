# 代表年校准算法

## 概述

代表年校准算法将短期测风塔观测数据调整为长期气候条件下的代表性数据。该方法结合短期实测数据与长期中尺度参考数据，使校准后的数据能够代表该地区的长期气候特征，为风能资源评估提供可靠的长期数据基础。

## 核心概念

### 什么是代表年

代表年是指能够反映某一地区长期气候特征的特定年份数据。在风能评估中，由于测风塔观测期通常只有一到三年，而风电场设计需要基于长期气候数据进行评估，因此需要将短期观测数据调整为具有长期代表性的数据序列。

代表年校准的核心思想是：利用中尺度再分析数据的长期历史（如 ERA5、MERRA-2 等提供 40 年以上的历史数据），建立中尺度数据与测风塔观测数据之间的统计关系，然后将这种关系应用于长期中尺度数据，生成具有长期代表性的合成数据序列。

### 短期数据与长期数据的差异

测风塔短期观测数据具有高精度、高时间分辨率的特点，但受限于观测期限，通常只能反映该时期的实际气候状况。而不同年份之间存在年际变异性，某些年份可能偏暖或偏冷，某些年份风速可能偏大或偏小。长期中尺度数据虽然空间分辨率较低、时间精度有限，但能够覆盖数十年的历史时期，捕捉气候的长期平均特征和年际变异性。

代表年校准算法通过统计方法将两者优势结合：用测风塔数据校正中尺度数据的系统性偏差，同时保留中尺度数据的长期变异性特征。

## 基本原理

### 校准原理

代表年校准基于一个基本假设：在观测期间内，中尺度数据与测风塔数据之间存在稳定的统计关系。这种关系反映了中尺度数据在特定地形条件下的局地化特征。通过建立这种关系，可以将长期中尺度数据转换为更准确的长期测风塔估算数据。

校准过程首先在观测期内的重叠时间段建立中尺度数据与测风塔数据的对应关系，然后评估这种关系的稳定性和可靠性，最后将验证后的关系应用于整个长期中尺度数据序列，生成校准后的代表年数据。

### 代表性评估

代表年数据需要满足两个基本条件：一是统计特性的代表性，即校准后的数据在平均风速、风速分布、极值特征等方面应与长期气候特征一致；二是时间变化的代表性，即季节变化、日变化、趋势变化等时间特征应符合长期气候规律。

校准过程中会评估候选代表年数据与长期参考数据之间的偏差，筛选出统计特性最接近长期平均的年份或数据段作为代表年数据。

## 应用场景

### 适用情况

代表年校准算法适用于以下场景：

**长期风能资源评估**：当需要基于短期观测数据评估风电场的长期发电潜力时，代表年校准能够将短期数据扩展为具有长期代表性的数据序列，为产能预测提供更可靠的数据基础。

**风电场设计参数确定**：风电场设计需要基于长期极端风速、湍流强度等参数，代表年校准能够提供这些参数的长期代表性估计。

**年发电量估算**：使用代表年数据进行年发电量估算，比直接使用短期观测数据具有更好的代表性和可靠性。

**不同风电场数据对比**：当需要对比不同地点或不同时间段的发电性能时，使用代表年数据可以消除年际气候变化的影响，使对比更加客观。

### 输入要求

进行代表年校准需要以下输入数据：

**处理后的测风塔时间序列数据**：经过数据清理、塔影校正等预处理的高质量观测数据。数据应包含风速、风向、温度、气压等气象要素，时间分辨率通常为 10 分钟。

**长期中尺度数据**：与测风塔位置对应的长期中尺度再分析数据。常用的数据源包括 ERA5（欧洲中期天气预报中心）、MERRA-2（NASA）、CFSR（美国国家环境预报中心）等。中尺度数据的时间跨度应尽可能长（建议 30 年以上），以捕捉气候的长期变异性。

**校准配置文件**：指定校准参数、目标年份范围、输出格式等的配置文件。配置文件中需要明确指定中尺度数据源、时间范围匹配规则、校准方法选择等关键参数。

### 输出结果

代表年校准的输出包括：

**校准后的代表年时间序列**：经过长期气候条件校准的时间序列数据，数据格式与输入的测风塔数据一致，可以直接用于后续的风能分析和发电量估算。

**校准信息报告**：记录校准过程的关键信息，包括参考年份、参与的传感器数量、数据覆盖情况等，帮助用户理解校准结果的可靠性。

## 工作流程

### 第一阶段：数据准备

首先加载测风塔处理后的时间序列数据，并将其裁剪到指定的校准时间范围内。同时加载所有中尺度数据源，建立中尺度数据与测风塔数据的对应关系。这一阶段需要确保数据的时间对齐和空间匹配正确。

### 第二阶段：模型加载

根据配置文件中的模型规格，加载预训练的中尺度-测风塔转换模型。该模型描述了中尺度数据在特定风向扇区内的统计转换关系，模型通常按 16 个风向扇区分别建立，以捕捉不同风向条件下的局地效应差异。

### 第三阶段：校准执行

使用加载的转换模型对测风塔数据进行校准。校准过程中，模型将长期中尺度数据转换为测风塔尺度的估算数据，并根据观测期内的统计关系进行调整。校准完成后，输出具有长期代表性的时间序列数据。

### 第四阶段：结果保存

将校准后的时间序列数据及其传感器描述信息保存到指定路径。保存的数据可以直接用于后续的风能分析和报告生成。

## 质量考虑

### 校准期长度

校准结果的可靠性很大程度上取决于校准期的长度。校准期应至少包含一年的完整季节变化，以建立中尺度数据与测风塔数据之间的稳定关系。建议校准期不少于六个月，且应尽量覆盖不同季节的风况特征。

### 参考数据质量

中尺度参考数据的质量直接影响校准结果。在使用中尺度数据之前，应评估其与测风塔观测数据的相关性和一致性。相关过低的数据源可能导致校准后的结果偏差较大。

### 校准不确定性

代表年校准存在固有的不确定性，主要来源于：观测期与长期平均气候的差异、转换模型的误差、中尺度数据本身的误差等。用户在解释和使用校准结果时，应考虑这些不确定性的影响。

## 实现细节

### 核心算法实现

代表年校准的核心实现位于 `src/RepresentativeYear/Core.jl` 和 `src/RepresentativeYear/Analysis.jl`。

#### 校准流程

**1. 气候学平均计算**

核心函数 `calculate_climatology_mean` 使用完整年份数据计算长期气候学平均。该函数首先调用 `find_climatology_timerange` 确定有效的时间范围。

**完整年份判定逻辑** (`find_climatology_timerange`):
- 起始年判定：如果数据从年初开始则包含该年，否则从下一年开始
- 结束年判定：如果数据到年末结束则包含该年，否则从上一年结束
- 最大跨度限制：30年（超过30年则取最近30年的数据）

此逻辑确保气候学平均计算基于完整年度数据，避免因数据不完整导致的统计偏差。源文件参考：`src/RepresentativeYear/Core.jl`。

**2. 校准必要性检查**

核心函数 `is_calibration_needed` 比较完整气候学期与训练期的平均风速，判断是否需要进行校准。该函数接收两个关键参数：完整时期的平均风速 (`full_period_mean`) 和训练期的平均风速 (`training_period_mean`)，以及一个可选的阈值参数（默认2%）。

**判定标准**：
- 计算完整期平均与训练期平均的相对差异
- 如果差异绝对值超过2%的阈值，则需要校准
- 如果差异在阈值范围内，直接返回原始数据，不进行校准

此机制避免了不必要的校准操作，确保只有当训练期数据与长期气候存在显著偏差时才进行修正。源文件参考：`src/RepresentativeYear/Core.jl`。

**3. 代表年查找**

核心函数 `find_representative_year` 在中尺度时间序列中寻找最具代表性的年份。该函数接收中尺度时间序列数据、气候学平均风速和传感器配置作为输入，使用2%阈值参数进行匹配判断。

**查找逻辑**：
- 算法从最新年份开始向前遍历历史数据
- 对每个完整年份计算年平均风速
- 找到第一个与气候学平均差异不超过2%的年份
- 返回该年份的起始时间戳（1月1日 00:00:00）

选择最新且符合条件的数据可以确保使用最接近当前观测条件的代表性年份。源文件参考：`src/RepresentativeYear/Core.jl`。

**4. 扇区差异计算**

函数 `calculate_sector_meso_diff` 计算训练期与代表年在16个风向扇区内的风速差异。该函数按风向扇区分别统计训练期和代表年的平均风速，然后计算两者的差值。

**计算逻辑**：
- 对16个风向扇区分别进行统计
- 每个扇区计算代表年平均风速 (`ref_year_mean_speed`)
- 每个扇区计算训练期平均风速 (`training_mean_speed`)
- 扇区差异 = 代表年平均风速 - 训练期平均风速

此差异值用于后续的校准调整，确保不同风向条件下的局地效应得到正确校准。源文件参考：`src/RepresentativeYear/Analysis.jl`。

**5. 校准应用**

核心函数 `apply_calibration` 将计算得到的校准量应用到原始时间序列数据。该函数接收待校准的时间序列、校准结果对象和中尺度时间序列数据作为输入，并使用最小风速0.5 m/s和最大风速25.0 m/s作为物理约束边界。

**校准公式**：
```
校准值 = 原始值 + 扇区中尺度差异 × 回归斜率
```

**公式参数说明**：
- `扇区中尺度差异` (`meso_speed_diff`): 当前数据点所属风向扇区的中尺度风速差异
- `回归斜率` (`slope`): 从训练模型获取的回归系数，反映中尺度数据与测风塔数据的转换关系
- 校准后的结果限制在物理合理范围内：[0.5, 25.0] m/s

此公式确保校准后的风速值既反映了长期气候特征，又保持在物理合理的范围内。源文件参考：`src/RepresentativeYear/Core.jl`。

**扇区确定** (`find_direction_sector`):

函数 `find_direction_sector` 将风向角度映射到16个风向扇区之一。该函数首先将输入角度归一化到0-360度范围，然后根据扇区边界计算所属扇区编号。

**扇区划分规则**：
- 将360度等分为16个扇区，每个扇区22.5度
- 扇区中心偏移11.25度，确保边界对称
- 扇区编号从1到16，返回整数类型

**计算公式**：
```
扇区编号 = floor((归一化角度 + 11.25) / 22.5) + 1
```

此映射确保风向数据被正确分配到对应的风向扇区，用于后续的分扇区校准处理。源文件参考：`src/RepresentativeYear/Core.jl`。

#### 关键参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 校准阈值 | 2% | 训练期与完整期平均差异超过此值才校准 |
| 代表年阈值 | 2% | 候选年与气候学平均的最大允许差异 |
| 最小风速 | 0.5 m/s | 校准后风速下限 |
| 最大风速 | 25.0 m/s | 校准后风速上限 |
| 最大气候学年限 | 30年 | 计算气候学平均时使用的最大年数 |
| 扇区数量 | 16 | 风向扇区划分数量 |

## 配置示例

```toml
[[masts]]
name = "TGL1"
input = { data = "./reconstruct-meso/TGL1.parquet" }
output = { data = "./representative-year/TGL1.parquet" }
time_range = { min = "2023-01-01T00:00:00", max = "2023-12-31T23:50:00" }

[masts.meso_model]
method = "16-sector"
meso_name = "era5"
model_file = "./meso-models/TGL1-era5.jld2"

[[mesos]]
name = "era5"
data = "./raw/era5.parquet"
sensors = "./raw/era5.sensors.toml"
```

## 默认推荐值

### 校准参数
- **校准阈值**: 2%（适用于大多数情况）
- **代表年阈值**: 2%（与校准阈值保持一致）
- **风速限制**: 0.5 - 25.0 m/s（符合物理合理性）

### 数据要求
- **最小训练期**: 6个月（确保季节性覆盖）
- **理想训练期**: 12个月（完整年度周期）
- **最大气候学期**: 30年（平衡计算效率与代表性）

### 质量检查
- 校准前检查训练期与完整期差异
- 自动跳过不需要校准的情况
- 校准后风速值限制在合理范围内

执行代表年校准使用以下命令：

```bash
julia bin/CleanMast.jl process representative-year --config <配置文件路径>

julia bin/CleanMast.jl recommend representative-year
```
