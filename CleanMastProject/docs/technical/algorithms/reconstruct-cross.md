# 跨测风塔重构算法

## 概述

跨测风塔重构算法利用不同测风塔之间的空间相关性来填补数据缺失。该方法通过建立测风塔间的风场关系模型，实现空间插值和数据融合，适用于测风塔网络密集的区域或需要扩展数据覆盖范围的场景。

## 理论基础

### 空间相关性理论

**距离衰减定律**
```
C(d) = C₀ × exp(-d/L)

其中：
- C(d): 距离d处的相关系数
- C₀: 零距离相关系数（通常为1）
- L: 相关长度尺度
- d: 测风塔间距离
```

**地形影响修正**
```
C_terrain(d) = C(d) × f_terrain(地形复杂度, 风向, 障碍物)

地形复杂度因子：
- 平坦地形: f_terrain = 1.0
- 丘陵地形: f_terrain = 0.8-0.9
- 山地地形: f_terrain = 0.6-0.8
- 复杂地形: f_terrain = 0.4-0.6
```

### 空间插值方法

**反距离权重插值 (IDW)**
```
插值公式：
Z(x₀) = Σ(w_i × Z_i) / Σ(w_i)

权重计算：
w_i = 1 / d_i^p

其中：
- Z(x₀): 目标位置插值结果
- Z_i: 第i个测风塔观测值
- d_i: 目标位置到第i个测风塔的距离
- p: 距离幂次参数（通常为2）
```

**克里金插值**
```
最优线性无偏估计：
Z*(x₀) = Σ(λ_i × Z(x_i))

约束条件：
Σ(λ_i) = 1 (无偏条件)
E[Z*(x₀) - Z(x₀)] = 0

变差函数：
γ(h) = 0.5 × E[(Z(x) - Z(x+h))²]
```

## 跨塔相关性建模

### 1. 距离相关性模型
```
算法：基于距离的相关性建模
输入：测风塔位置坐标, 同期观测数据

步骤1：距离计算
    for i, j in 测风塔对:
        计算欧氏距离：
        d_ij = sqrt((x_i - x_j)² + (y_i - y_j)²)

步骤2：经验相关性分析
    for 每个距离段:
        distance_bins = [0-5km, 5-10km, 10-20km, 20-50km, >50km]

        计算该距离段内的平均相关系数：
        r_bin = mean(correlation(WS_i, WS_j)) for d_ij in bin

步骤3：相关性模型拟合
    拟合指数衰减模型：
    r(d) = r₀ × exp(-d/L) + r_∞

    其中：
    - r₀: 初始相关系数
    - L: 相关长度尺度
    - r_∞: 长距离渐近相关系数

步骤4：模型验证
    计算拟合优度：
    R² = 1 - SS_res/SS_tot

    if R² < 0.7:
        采用分段线性模型或样条插值
```

### 2. 地形修正相关性模型
```
算法：地形修正相关性建模
输入：测风塔位置, 数字高程模型(DEM), 观测数据

步骤1：地形特征提取
    for 每对测风塔:
        计算地形指标：
        - 高程差: Δh = |h_i - h_j|
        - 坡度变化: slope_variation
        - 粗糙度变化: roughness_variation
        - 遮挡因子: shelter_factor

步骤2：地形影响量化
    计算地形复杂度指数：
    TCI = w₁×(Δh/h_scale) + w₂×slope_var + w₃×roughness_var

    地形修正因子：
    f_terrain = exp(-α × TCI)

    其中α为经验参数

步骤3：修正相关性模型
    r_corrected(d) = r_distance(d) × f_terrain(TCI)

    拟合参数：
    使用非线性最小二乘法拟合修正模型参数

步骤4：模型优化
    交叉验证优化权重参数：
    for k_fold in cross_validation:
        训练修正模型
        验证预测精度
    选择最优参数组合
```

### 3. 风向相关性模型
```
算法：风向相关的空间相关性
输入：测风塔观测数据, 主导风向信息

步骤1：风向分层
    将数据按风向分层：
    wind_direction_sectors = [0-45°, 45-90°, 90-135°, ..., 315-360°]

步骤2：风向特定相关性
    for each sector:
        计算该风向段的测风塔间相关性：
        r_sector = correlation(WS_i_sector, WS_j_sector)

        考虑风向影响：
        - 上风向测风塔权重更高
        - 下风向考虑尾流效应
        - 侧风向考虑平行流动

步骤3：相关性模型
    构建风向相关的相关性函数：
    r(d, θ) = r_base(d) × f_direction(θ, terrain)

    其中：
    - θ: 相对于主导风向的角度
    - f_direction: 风向修正函数

步骤4：模型应用
    根据实时风向选择相应的相关性模型：
    当前风向 → 选择对应扇区模型 → 计算权重
```

## 空间插值重构算法

### 1. 反距离权重重构
```
算法：反距离权重空间重构
输入：目标测风塔位置, 参考测风塔数据, 距离幂次参数

步骤1：参考塔筛选
    for 每个参考测风塔:
        计算到目标位置的距离: d_i

    筛选条件：
    - 距离 < max_distance (如50km)
    - 当前时刻有有效数据
    - 历史相关性 > min_correlation

步骤2：权重计算
    for 每个有效参考塔:
        基础权重: w_basic = 1 / d_i^p

        相关性修正: w_corr = w_basic × r_i

        数据质量修正: w_quality = w_corr × quality_i

    权重归一化: w_i = w_quality_i / Σ(w_quality)

步骤3：空间插值
    for t in missing_timestamps:
        available_refs = 筛选有效参考数据

        if len(available_refs) >= min_refs:
            插值结果:
            WS_target(t) = Σ(w_i × WS_ref_i(t))

            不确定度估计:
            σ_interpolation = sqrt(Σ(w_i × σ_ref_i²))

步骤4：结果质量控制
    物理合理性检查：
    - 风速非负
    - 风速 < 物理最大值
    - 与邻近观测一致性检查
```

### 2. 克里金插值重构
```
算法：克里金空间插值重构
输入：测风塔网络数据, 变差函数模型

步骤1：变差函数建模
    计算经验变差函数：
    for 距离滞后 h:
        γ(h) = 0.5 × mean((Z(x_i) - Z(x_i + h))²)

    拟合理论变差函数：
    γ(h) = C₀ + C₁ × [1 - exp(-h/a)]  # 指数模型
    或
    γ(h) = C₀ + C₁ × [1.5×h/a - 0.5×(h/a)³]  # 球形模型

步骤2：克里金方程组
    构建克里金方程组：
    [K  1] [λ] = [k]
    [1ᵀ 0] [μ]   [1]

    其中：
    - K: 协方差矩阵
    - λ: 权重向量
    - μ: 拉格朗日乘数
    - k: 待插值点与已知点的协方差向量

步骤3：求解权重
    求解线性方程组得到权重：
    λ = K⁻¹ × (k - 1×μ)

    其中μ = (1ᵀK⁻¹k - 1) / (1ᵀK⁻¹1)

步骤4：插值预测
    克里金插值值：
    Z*(x₀) = Σ(λ_i × Z(x_i))

    克里金方差：
    σ²_k = γ(0) - Σ(λ_i × γ(x_i, x₀)) - μ

步骤5：结果验证
    交叉验证检查：
    for 每个已知点:
        去除该点，用其余点插值
        计算预测误差

    计算验证统计量：
    ME = mean(预测值 - 观测值)  # 平均误差
    RMSE = sqrt(mean((预测值 - 观测值)²))
```

### 3. 多变量空间插值
```
算法：多变量协同克里金插值
输入：主变量(风速), 协变量(风向、温度、气压)

步骤1：变量相关性分析
    计算变量间交叉相关性：
    for 主变量 vs 协变量:
        cross_correlation = corr(primary_var, co_var)

    如果交叉相关性 > threshold:
        纳入协同克里金模型

步骤2：交叉变差函数
    计算直接变差函数和交叉变差函数：
    γ₁₁(h) = 0.5 × E[(Z₁(x) - Z₁(x+h))²]  # 主变量自变差
    γ₂₂(h) = 0.5 × E[(Z₂(x) - Z₂(x+h))²]  # 协变量自变差
    γ₁₂(h) = 0.5 × E[(Z₁(x) - Z₁(x+h))(Z₂(x) - Z₂(x+h))]  # 交叉变差

步骤3：协同克里金方程
    扩展的克里金方程组：
    [K₁₁ K₁₂ 1₁] [λ₁]   [k₁₀]
    [K₂₁ K₂₂ 1₂] [λ₂] = [k₂₀]
    [1₁ᵀ 1₂ᵀ 0 ] [μ ]   [1  ]

步骤4：多变量插值
    主变量插值：
    Z₁*(x₀) = Σ(λ₁ᵢ × Z₁(xᵢ)) + Σ(λ₂ⱼ × Z₂(xⱼ))

    利用协变量信息提高插值精度
```

## 重构质量评估

### 空间重构精度评估
```
算法：跨塔重构精度评估
输入：重构结果, 验证数据

1. 留一交叉验证:
   for 每个测风塔:
       temporarily_remove(tower_i)
       使用其余测风塔重构tower_i数据
       计算重构误差

2. 空间误差分析:
   计算距离相关的误差：
   error_vs_distance = group_by_distance(errors, distances)

   分析误差空间分布：
   - 网络中心误差较小
   - 网络边缘误差较大
   - 地形复杂区域误差增大

3. 重构稳定性:
   扰动测试：
   for perturbation_test:
       随机去除部分参考数据
       重新执行重构
       比较结果稳定性
```

### 不确定度量化
```
算法：跨塔重构不确定度量化

1. 插值不确定度:
   基于权重分布：
   σ_spatial = sqrt(Σ(w_i² × σ_i²))

   其中σ_i为各参考塔的观测不确定度

2. 模型不确定度:
   相关性模型误差：
   σ_model = std(r_observed - r_modeled)

   传播到插值结果：
   σ_propagated = |∂Z/∂r| × σ_model

3. 总不确定度:
   σ_total = sqrt(σ_spatial² + σ_model² + σ_systematic²)

   置信区间：
   CI = Z_interpolated ± t_α/2 × σ_total
```

## 应用策略

### 测风塔网络优化
```
指导原则：
1. 网络密度要求:
   - 平坦地形: 测风塔间距 < 10km
   - 丘陵地形: 测风塔间距 < 5km
   - 复杂地形: 测风塔间距 < 3km

2. 代表性要求:
   - 覆盖主要地形类型
   - 包含不同粗糙度区域
   - 考虑主导风向分布

3. 冗余度设计:
   - 每个目标位置至少3个参考塔
   - 参考塔分布避免共线性
   - 不同距离尺度的参考塔组合
```

### 算法选择指南
```
条件评估矩阵：
                    IDW    普通克里金  协同克里金  多变量融合
测风塔数量 < 5      ✓      ×          ×          ×
测风塔数量 5-10     ✓      ✓          ×          ×
测风塔数量 > 10     ✓      ✓          ✓          ✓
地形复杂度低        ✓      ✓          ✓          ✓
地形复杂度高        ×      ✓          ✓          ✓
数据稀疏            ✓      ×          ×          ×
数据密集            ✓      ✓          ✓          ✓
计算资源有限        ✓      ×          ×          ×
精度要求高          ×      ✓          ✓          ✓
```

### 参数推荐值
```
通用参数：
- IDW距离幂次: p = 2.0
- 最大插值距离: 50km (平坦), 20km (复杂地形)
- 最小参考塔数量: 3个
- 相关性阈值: > 0.6

特定环境调整：
- 海上风场: 增大插值距离，降低相关性要求
- 山地风场: 减小插值距离，增加地形修正
- 风电场群: 考虑尾流效应，调整权重分配
```

通过系统化的跨测风塔重构算法，可以充分利用测风塔网络的空间信息，实现更大范围、更高精度的风能数据重构和资源评估。
