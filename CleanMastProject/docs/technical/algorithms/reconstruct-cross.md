# 跨测风塔重构算法

## 算法概述

**跨测风塔重构**（Cross-Mast Reconstruction）是一种利用测风塔网络空间相关性进行数据填补的方法。当项目区域内存在多个测风塔时，可以利用它们之间风场特征的相似性，用数据完整的测风塔来重建存在数据缺失的测风塔。

该算法假设：地理位置相近的测风塔经历相似的风况条件，因此可以通过建立塔间关系模型来推断缺失数据。

## 核心原理

### 空间相关性原理

相邻测风塔之间存在风场相关性，这种相关性是跨塔重构的基础：

- **相关性基础**：距离较近的测风塔通常表现出相似的风速变化趋势和风向特征
- **数据互补**：当某一测风塔出现数据缺失时，可通过相关性强的邻近塔进行推算
- **模型化关系**：通过分析历史同期数据，建立塔间定量关系模型

### 两阶段执行模式

跨测风塔重构分为两个独立阶段：

1. **训练阶段**（`train reconstruct-cross`）：分析塔间关系，建立预测模型
2. **重构阶段**（`process reconstruct-cross`）：应用训练好的模型，填补目标塔数据

两个阶段可以独立运行，便于根据数据情况灵活调整。

## 适用场景

### 典型应用情境

跨测风塔重构适用于以下情况：

- **多塔项目**：项目区域内有多个测风塔（建议至少3座及以上）
- **数据不均衡**：部分塔数据完整度高，部分塔存在较多缺失
- **塔间距离适中**：测风塔间距在合理范围内（需根据地形判断）
- **同期观测**：各塔有重叠的时间段可用于训练分析

### 不适用场景

- 单塔项目（无可用参考塔）
- 塔间距离过远或地形复杂导致相关性弱
- 各塔观测时段完全不重叠
- 数据质量普遍较差，无法建立可靠模型

## 输入与输出

### 训练阶段输入

训练阶段需要以下输入数据：

- **测风塔时间序列**：所有参与训练的测风塔清洗后数据
- **训练配置**：包含最小重叠天数、最小数据点等参数
- **测风塔列表**：参与训练的塔及其输入输出路径

### 训练阶段输出

训练阶段生成以下输出：

- **风速模型文件**：各合格塔对的风速相关性模型（JLD2格式）
- **风向模型文件**：各合格塔对的风向关系模型（JLD2格式）
- **训练结果报告**：机器可读的TOML格式结果摘要

### 重构阶段输入

重构阶段需要以下输入数据：

- **训练阶段模型**：训练好的跨塔重构模型
- **重构配置**：包含重构任务优先级、目标塔与源塔映射关系
- **原始时间序列**：需要重建的目标塔数据

### 重构阶段输出

重构阶段生成以下输出：

- **重建后时间序列**：填补缺失数据后的完整时间序列
- **质量评估报告**：各重构任务的填充率和相关性指标
- **汇总摘要**：整体重构效果的统计报告

## 执行步骤

### 训练阶段步骤

训练阶段按以下步骤执行：

1. **加载配置**：读取训练配置文件，验证参数有效性
2. **数据加载**：读取所有参与塔的时间序列数据
3. **塔对分析**：遍历所有塔对组合（目标塔 ← 源塔）
4. **相关性分析**：分析每对塔的风速相关性和风向关系
5. **模型训练**：对符合条件的塔对建立预测模型
6. **结果保存**：保存模型文件和训练摘要

### 重构阶段步骤

重构阶段按以下步骤执行：

1. **加载配置**：读取重构配置文件和模型路径
2. **数据加载**：加载所有目标塔和源塔的时间序列
3. **任务执行**：按优先级顺序执行各重构任务
4. **数据融合**：将模型推算结果融入目标塔数据（仅填补缺失值）
5. **质量计算**：计算各重构任务的填充率和相关性指标
6. **结果输出**：保存重建后数据和质量报告

## 质量影响因素

### 塔间距离

塔间距离是影响重构质量的首要因素：

- **近距离优势**：距离较近的塔相关性通常更强
- **距离阈值**：超过一定距离后相关性显著下降
- **地形影响**：距离相同时，地形复杂度的差异会产生不同效果

### 地形特征

地形条件对塔间相关性有显著影响：

- **平坦地形**：相关性随距离衰减较慢，重构效果好
- **复杂地形**：地形切割可能导致局部风场差异，影响相关性
- **高程差异**：塔间高差过大时需特别评估相关性

### 相关性强度

训练阶段分析得出的相关性强度直接决定重构质量：

- **高相关性（>0.8）**：重构结果可信度高
- **中等相关性（0.6-0.8）**：重构结果可作为参考
- **低相关性（<0.6）**：不建议使用该塔对进行重构

## 配置要点

### 训练配置参数

训练阶段需要设置以下关键参数：

- **最小重叠天数**：用于训练的塔间数据重叠时长要求
- **最小数据点**：参与相关性分析的最小有效数据量
- **相关性阈值**：判定塔对是否合格的相关性标准

### 重构配置参数

重构阶段需要设置以下关键参数：

- **重构任务定义**：明确每对塔的目标-源关系和重构变量
- **优先级设置**：定义各重构任务的执行顺序
- **输出路径**：指定重建后数据的保存位置

## 结果评估

### 填充率指标

填充率反映重构的数据覆盖能力：

- **计算方式**：成功填补的缺失点数 / 原始缺失点总数
- **理想状态**：接近100%的填充率表示大多数缺失得到填补
- **注意**：填充率高不代表质量好，需结合相关性评估

### 相关性指标

相关性反映重构数据的可靠性：

- **来源**：使用训练阶段分析得出的塔间相关系数
- **解读**：相关系数越高，推算值与真实值越接近
- **风向差异**：风向重构使用标准差指标评估

## 实现细节

### 核心算法实现

跨测风塔重构的核心实现位于 `src/TrainReconstructCross/` 和 `src/ReconstructCross/` 目录。

#### 数据覆盖分析

**重叠期计算**

实现见 `src/TrainReconstructCross/DataCoverage.jl`。

该模块分析两个测风塔之间的时间序列重叠情况和数据可用性：

1. **最高层传感器定位**：从各塔传感器列表中筛选出最高层的风速传感器（statType为avg）
2. **有效时间戳提取**：获取每个传感器具有有效数据（非缺失）的时间戳列表
3. **重叠时间戳计算**：取两组时间戳的交集，得到共同的观测时间段
4. **重叠天数计算**：基于10分钟间隔统计，重叠天数 = 并发记录数 × 10分钟 ÷ (60×24)
5. **覆盖率计算**：覆盖率 = 实际重叠记录数 ÷ 理论潜在记录数 × 100%

**关键参数**：
- 使用最高层风速传感器（avg类型）进行覆盖分析
- 时间间隔：10分钟
- 覆盖率 = 实际重叠记录数 / 理论潜在记录数

#### 风速相关性分析

**相关性计算**

实现见 `src/TrainReconstructCross/CrossMastSpeedCorrelation.jl`。

该模块分析两塔之间风速传感器的相关性并建立线性回归模型：

1. **传感器配对**：遍历目标塔与源塔之间所有风速传感器组合
2. **数据合并**：按时间戳内连接两个塔的传感器数据
3. **数据量验证**：要求最少100个有效并发数据点，否则跳过
4. **皮尔逊相关系数**：计算目标与源风速的线性相关程度
5. **线性回归拟合**：建立预测模型：目标值 = 斜率 × 源值 + 截距

**模型训练与筛选**

训练函数根据配置参数筛选合格的传感器配对：

1. **相关性阈值过滤**：保留相关系数 ≥ 最小相关系数阈值的配对
2. **数据量过滤**：保留有效数据点 ≥ 最小数据点要求的配对
3. **排序优化**：按相关系数降序排列，优先使用高相关性配对
4. **模型构建**：将合格配对组合成完整的跨塔风速模型

**重构执行**

重构函数应用训练好的模型填补目标塔缺失数据：

1. **缺失值识别**：仅对目标列中缺失且源数据有效的时间点进行重构
2. **线性变换**：使用模型斜率和截距计算推算值：重构值 = 斜率 × 源值 + 截距
3. **合理性约束**：将重构风速限制在 [0, 50] m/s 物理范围内
4. **渐进式填补**：按优先级顺序应用多个配对，仅填补仍为缺失的位置

#### 关键参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 最小数据点 | 100 | 参与相关性分析的最小数据量 |
| 最小相关系数 | 0.7 | 风速重构的相关系数阈值 |
| 风速上限 | 50 m/s | 重构结果上限 |
| 风速下限 | 0 m/s | 重构结果下限 |
| 风向标准差阈值 | 12.5° | 风向重构的质量阈值 |
| 最小重叠天数 | 120天 | 训练所需的最小重叠期 |

## 配置示例

### 训练配置

```toml
[[masts]]
name = "TGL1"
input = { data = "./clean/TGL1.parquet", sensors = "./clean/TGL1.sensors.toml" }

[[masts]]
name = "TGL2"
input = { data = "./clean/TGL2.parquet", sensors = "./clean/TGL2.sensors.toml" }

[train]
min_overlap_days = 120
min_correlation_speed = 0.7
min_correlation_direction = 0.5
max_direction_std = 12.5
output_dir = "./cross-mast-models"
```

### 重构配置

```toml
[[reconstructions]]
target_mast = "TGL1"
source_masts = ["TGL2", "TGL3"]
priority = 1

[reconstructions.model]
model_file = "./cross-mast-models/TGL1_TGL2.jld2"
```

## 默认推荐值

### 训练参数
- **最小重叠天数**: 120天（确保足够的季节性覆盖）
- **风速相关系数阈值**: 0.7（保证重构质量）
- **风向相关系数阈值**: 0.5
- **风向标准差阈值**: 12.5°

### 重构策略
- **优先级设置**: 高相关性塔对优先执行
- **仅填补缺失**: 保留原始有效数据
- **多源重构**: 支持多个源塔依次重构

### 质量评估
- **填充率**: 成功填补的缺失点比例
- **平均相关系数**: 使用模型的平均相关性
- **高度覆盖**: 各高度层的重构成功率

## 注意事项

1. **数据时序对齐**：确保训练数据与重构数据在时间上正确对齐
2. **模型时效性**：训练结果反映特定时期的塔间关系
3. **结果验证**：建议对重构结果进行合理性检查
4. **多次迭代**：必要时可多次迭代训练-重构过程以优化结果
