# 单测风塔重构算法

## 算法概述

单测风塔重构算法利用同一测风塔不同高度传感器间的相关性来填补数据缺失。该方法基于大气边界层的基本原理：近地层中不同高度的风速和风向存在系统性关联，可通过相关性建模实现缺失数据的估计重建。

## 核心概念

**算法定位**：单测风塔重构是数据重构管线中的第一层重建策略，优先于中尺度数据重构使用。当单塔自身具备足够的冗余传感器时，应优先采用此方法，因其精度通常高于跨数据源的重构方式。

**方法本质**：利用测风塔上多个高度层传感器之间的统计相关性，建立参考高度与目标高度之间的映射关系，进而对缺失数据进行估算。风速和风向分别采用不同的重构策略，以适应各自的数据特性。

## 基本原理

### 高度相关性原理

大气边界层中，不同高度的风速和风向存在物理关联。近地层风速随高度增加呈现对数或幂律增长趋势，风向随高度变化呈现埃克曼螺旋特征。测风塔上部署于不同高度的传感器，其测量值应反映这种物理关联，因此可通过相关性分析建立高度间的定量关系。

### 统计建模基础

通过历史观测数据中参考高度与目标高度同时有效的样本对，建立两者之间的统计回归模型。模型的质量取决于样本数量和相关性强度。当相关性达到一定阈值时，模型可用于估算目标高度的缺失值。

### 时段分组策略

为捕捉风况的日内变化特征，重构过程按小时分组进行。同一小时内的大气条件相对稳定，不同日期同时段的相似性更高，有助于提高相关性建模的准确性。

## 适用场景

### 典型应用

- 单个高度层传感器短时间缺失的数据填补
- 多高度层测风数据的相互验证和补充
- 塔影校正后缺失值的后续重建
- 数据清理阶段标记为可恢复的异常值填补

### 适用条件

- 目标高度存在有效的参考传感器
- 参考高度与目标高度的数据相关性满足要求
- 缺失时段存在有效的参考数据
- 数据缺失比例适中，重构具有物理意义

### 限制条件

- 大范围连续缺失（超过数小时或数天）时重构可靠性下降
- 极端天气事件期间相关性可能减弱
- 静风条件下风向重构不确定性显著增加
- 传感器全部失效的高度层无法进行重构

## 输入要求

### 数据输入

- 预处理后的完整时间序列数据
- 包含时间戳和多个高度层的风速、风向测量值
- 传感器配置信息，明确各传感器的安装高度和测量类型
- 时间序列应已完成正则化处理，间隔一致

### 配置参数

- 需要重建的目标高度列表
- 各高度层可用的参考传感器选择
- 相关性阈值设定
- 重构质量控制参数

## 输出结果

### 数据输出

- 填补缺失值后的完整时间序列
- 保持原始时间分辨率和传感器配置
- 标记重构数据点以便后续追溯

### 统计输出

- 重构成功与失败的统计汇总
- 各传感器的重构成功率
- 重构质量评估指标

## 质量考虑

### 影响因素

- 参考数据与目标数据的相关性强度是最关键因素
- 重构时段的长度影响模型可靠性
- 风速水平影响风向重构的准确性
- 季节和大气稳定度变化可能导致相关性波动

### 准确性评估

重构精度受多种因素制约，相关性强的时段重构结果更可靠。极端风况和静风条件下的重构不确定性较高。应对重构结果进行合理性检验，剔除明显不合理的估算值。

### 质量控制

应对重构结果进行物理合理性检查，包括风速非负、风向连续性、风切变指数合理性等约束条件。不满足物理约束的重构结果应标记为无效或降级处理。

## 与其他重构方法的比较

单测风塔重构的精度通常高于中尺度数据重构，原因在于同一塔上不同高度传感器间的相关性远强于空间分离的测风塔或中尺度数据源间的相关性。因此，应优先使用单塔重构策略，仅在单塔自身无法满足重构需求时才考虑中尺度数据融合。

## 应用指导

单测风塔重构是数据处理管线中的首选重建策略，适用于填补小范围、分散的数据缺失。处理流程首先对时间序列进行正则化处理，确保时间间隔一致；然后按小时分组进行相关性建模；最后将估算值填入对应缺失位置。通过合理配置参数和严格的质量控制，可实现高精度的数据重建效果。

## 实现细节

### 缺失数据识别

缺失数据通过 `ismissing()` 函数检测。所有 `WindSpeed` 和 `WindDirection` 类型的传感器（`statType == "avg"`）都会在以下条件下被识别为重构目标：

- 高度 ≥ 50m（默认阈值）
- 该时刻该高度层的测量值缺失
- 同一小时内至少有 3 个高度层满足可用性要求

### 高度层筛选

**筛选标准（`select_reconstruction_layers` 函数）**：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 最低高度阈值 | 50.0 m | 只考虑高度 > 50m 的传感器 |
| 最小数据可用率 | 50% | 该小时内有效数据比例 ≥ 0.5 |
| 最少合格层数 | 3 层 | 不足 3 层则跳过该小时 |

**筛选流程**：
1. 过滤出高度 > 50m 的传感器
2. 计算每个传感器在当前小时内的数据可用率
3. 保留可用率 ≥ 50% 的传感器
4. 按高度降序排列，取前 3 层作为重构层

若某小时满足条件的传感器不足 3 层，则该小时所有缺失数据均不进行重构。

### 风速重构算法

**核心公式（幂律风切变）**：

$$v_{target} = v_{ref} \times \left(\frac{h_{target}}{h_{ref}}\right)^{\alpha}$$

其中：
- $v_{target}$：目标高度估算风速
- $v_{ref}$：参考层实际风速（该时刻可用的最高层）
- $h_{target}$：目标高度
- $h_{ref}$：参考层高度
- $\alpha$：风切变指数（每小时计算一次）

**风切变指数计算（`calculate_shear_exponent` 函数）**：

1. 获取当前小时内各层的平均风速
2. 使用对数线性回归拟合幂律关系
3. 回归方程：$\ln(v/v_{ref}) = \alpha \times \ln(h/h_{ref})$
4. 限制范围：$\alpha \in [-0.25, 1.25]$（物理合理区间）

**参考层选择**：

对于每个具体时刻，重构时动态选择参考层：
- 遍历 top 3 层（从高到低）
- 跳过目标高度自身
- 选择该时刻有有效测量值的最高层
- 有效测量值条件：非缺失、> 0、≤ 100 m/s

**风速重构验证**：

重构结果必须满足：
- 非 NaN、非 Inf
- > 0（物理约束：风速不能为负）
- ≤ 100 m/s（极端风速上限）

不满足验证条件的重构标记为失败。

### 风向重构算法

**核心思路（向量平均法）**：

1. 将风向转换为向量分量（速度加权）
2. 计算各层的平均向量方向
3. 建立目标层与顶层之间的方向差 profile
4. 重构时：$D_{target} = D_{top} + \Delta D$

**向量转换公式**：

$$x = v \times \sin(\theta), \quad y = v \times \cos(\theta)$$

其中 $\theta$ 为风向（度），$v$ 为风速（用于加权）

**向量平均方向计算（`vector_to_direction` 函数）**：

$$D = \text{mod}(\text{atan2}(\bar{x}, \bar{y}) \times \frac{180}{\pi} + 360, 360)$$

其中 $\bar{x}$、$\bar{y}$ 为分量均值

**方向差计算（`calculate_hourly_direction_difference` 函数）**：

- 计算目标层的平均向量方向
- 计算顶层的平均向量方向
- 取最短角距离：$\Delta D = D_{target} - D_{top}$

**风向重构验证**：

- 参考层（顶层）必须在该时刻有有效测量值
- 目标高度必须在 direction profile 中存在对应差值
- 重构结果归一化到 $[0, 360)$ 范围

### 小时分组策略

**分组逻辑（`GroupByHour` 模块）**：

1. 添加 `hour` 列：每个时间戳所属的整点小时
2. 按 `hour` 列分组
3. 对每个小时独立执行重构流程

**分组意义**：
- 大气边界层在同一小时内相对稳定
- 便于计算小时平均风切变和方向差
- 每小时重构 profile 反映该时段的大气状态

### 重构流程图

```
输入时间序列数据
       ↓
时间正则化（检测代表性间隔，如10分钟）
       ↓
按小时分组
       ↓
┌─────────────────┬─────────────────┐
│   风速重构       │   风向重构       │
├─────────────────┼─────────────────┤
│1. 筛选有效传感器 │1. 筛选有效传感器 │
│2. 选择 top 3 层 │2. 选择 top 3 层 │
│3. 计算小时平均   │3. 计算小时平均   │
│4. 拟合风切变指数 │4. 计算方向差     │
│5. 逐点重构       │5. 逐点重构       │
│6. 验证结果      │6. 验证结果      │
└─────────────────┴─────────────────┘
       ↓
合并成功/失败结果
       ↓
应用成功重构到数据框
       ↓
输出结果和统计
```

### 重构失败原因

| 失败原因 | 说明 |
|----------|------|
| `Target sensor not in top 3 layers` | 目标传感器未被选入 top 3 层 |
| `No valid reference layer at this timestamp` | 该时刻无可用参考层 |
| `Reconstructed speed is invalid: $value` | 重构风速超出物理范围 |
| `Failed to calculate wind shear exponent` | 无法计算风切变指数（数据不足） |
| `Top layer direction not available at this timestamp` | 顶层风向缺失 |
| `Failed to calculate direction profile` | 无法建立方向差 profile |

## 配置示例

```toml
# 单测风塔重构配置
# 文件: reconstruct-single.toml

[[masts]]
name = "pn-002824"

[masts.input]
data = "./tower-shading/pn-002824.csv"
sensors = "./tower-shading/pn-002824.sensors.yaml"

[masts.output]
data = "./reconstruct-single/pn-002824.csv"
sensors = "./reconstruct-single/pn-002824.sensors.yaml"

[[masts]]
name = "pn-013945"

[masts.input]
data = "./tower-shading/pn-013945.csv"
sensors = "./tower-shading/pn-013945.sensors.yaml"

[masts.output]
data = "./reconstruct-single/pn-013945.csv"
sensors = "./reconstruct-single/pn-013945.sensors.yaml"
```

**配置说明**：

- `[[masts]]`：数组配置块，支持多个测风塔
- `name`：测风塔标识符，必须与前序步骤（如 tower-shading）一致
- `input.data`：输入数据文件路径（来自 tower-shading 步骤）
- `input.sensors`：输入传感器配置文件路径
- `output.data`：输出数据文件路径
- `output.sensors`：输出传感器配置文件路径

## 默认推荐值

### 重构层筛选参数

| 参数 | 默认值 | 推荐范围 | 说明 |
|------|--------|----------|------|
| 最低高度阈值 | 50.0 m | 40-60 m | 只考虑此高度以上的传感器 |
| 最小数据可用率 | 0.5 | 0.3-0.7 | 该小时内有效数据比例阈值 |
| 最少合格层数 | 3 层 | 3 层 | 不足此数则跳过该小时 |

### 风速重构参数

| 参数 | 默认值 | 推荐范围 | 说明 |
|------|--------|----------|------|
| 风切变指数下限 | -0.25 | -0.3 ~ -0.2 | 极端不稳定大气层结 |
| 风切变指数上限 | 1.25 | 1.0 ~ 1.5 | 极端稳定大气层结 |
| 风速有效范围 | (0, 100] m/s | (0, 50] m/s（常规） | 超出范围标记为失败 |

### 风向重构参数

| 参数 | 默认值 | 推荐范围 | 说明 |
|------|--------|----------|------|
| 参考层选择 | 顶层 | 顶层 | 始终使用最高有效层 |
| 方向平均法 | 向量平均 | 向量平均 | 速度加权计算 |

### 处理流程参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 代表性间隔 | 自动检测 | 通常为 10 分钟 |
| 目标传感器类型 | WindSpeed, WindDirection | 仅重构平均统计量（avg） |
| 输出标记 | 原位更新 | 直接替换 DataFrame 中的缺失值 |

### 使用建议

1. **最低高度阈值**：根据测风塔实际配置调整。如果 50m 以下有较多有效传感器，可适当降低此值以增加可用层数。

2. **数据可用率**：小时可用率 ≥ 50% 是保守阈值。若某小时数据缺失较多但仍有一定参考价值，可降低至 0.3-0.4。

3. **风速范围**：100 m/s 是宽松上限，实际风况极少超过 50 m/s。严格控制时可设为 50 m/s 以过滤明显不合理值。

4. **多层塔优势**：测风塔高度层越多（建议 ≥ 4 层），重构成功率越高。因 top 3 层选择有更大灵活性。
