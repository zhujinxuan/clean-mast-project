# 风电机组时间序列提取算法

## 概述

风电机组时间序列提取算法用于从测风塔代表性年数据中提取指定轮毂高度处的风速和风向数据。该算法通过分析测风塔上安装的多个高度传感器，选择距离目标轮毂高度最近的传感器数据，为风电机组设计与载荷分析提供输入文件。

## 算法概念

### 核心目标

为风电机组仿真软件（如 Meteodyn WT）生成符合特定格式要求的时间序列输入文件。轮毂高度通常远高于测风塔最高传感器安装高度，因此需要从多个测量高度中提取最接近目标高度的数据。

### 数据来源

输入数据为经过代表性年校准的时间序列文件，包含时间戳、多个高度的风速传感器读数和风向传感器读数。这些传感器以平均统计类型记录每十分钟或每小时的数据值。

### 处理流程

算法首先加载配置文件中定义的所有测风塔及其对应的目标轮毂高度列表。对于每个测风塔，程序读取其代表性年时间序列数据，然后在指定的目标高度列表中逐个处理。对于每个目标高度，系统自动搜索距离该高度最近的可用风速传感器和风向传感器，提取相应的数据列，最终将结果保存为结构化的 CSV 文件。

## 使用场景

### 适用情况

本算法适用于以下场景：

- **风电机组设计阶段**：需要了解特定轮毂高度处的风况特征，为机组选型提供依据
- **载荷计算**：风电机组仿真软件需要特定高度处的风速风向时间序列作为输入
- **产能估算**：结合轮毂高度的风速数据评估风电场的年发电量潜力
- **可行性研究**：在项目规划阶段评估不同轮毂高度方案的经济性

### 输入要求

- 代表性年时间序列数据文件（包含完整时间戳和传感器数据）
- 配置文件指定每个测风塔对应的目标轮毂高度
- 测风塔数据中需包含足够高度范围的传感器

## 配置参数

### 测风塔配置

每个测风塔需要定义以下信息：

- **测风塔标识名称**：用于生成输出文件名
- **输入数据路径**：代表性年时间序列文件的位置
- **目标高度列表**：需要提取数据的轮毂高度值
- **输出目录路径**：生成文件的目标保存位置

### 高度选择原则

选择目标高度时应考虑以下因素：

- 目标高度应接近或略高于测风塔最高传感器安装高度
- 确保有足够的测量高度用于评估风切变特性
- 多个目标高度可以同时处理，便于进行敏感性分析

## 输出说明

### 文件格式

生成的文件为标准 CSV 格式，包含三列数据：

- **timestamp**：时间戳，记录数据采集的精确时刻
- **wind_speed**：风速值，单位为米每秒
- **wind_direction**：风向值，单位为度

### 文件命名

输出文件按照约定格式命名，格式为：`{测风塔名称}-{高度值}m.csv`。例如，`mast-01-120_0m.csv` 表示一号测风塔、一百二十米高度的时间序列数据。

## 处理步骤

### 步骤一：配置解析

读取 TOML 格式的配置文件，解析所有测风塔及其对应的目标高度列表。系统会验证配置文件的有效性，确保每个测风塔都包含必要的参数信息。

### 步骤二：数据加载

对于每个配置的测风塔，加载其代表性年时间序列数据文件。数据文件中包含时间戳和所有可用传感器的测量值。

### 步骤三：传感器匹配

对于每个目标高度，系统在测风塔的所有传感器中搜索距离该高度最近的风速传感器和风向传感器。优先选择统计类型为平均值的传感器数据。

### 步骤四：数据提取与保存

从完整时间序列中提取匹配传感器对应的数据列，按照标准格式整理后保存为独立的 CSV 文件。每个目标高度生成一个独立的输出文件。

## 实现细节

### 核心算法实现

风电机组时间序列提取的核心实现位于 `src/WTTimeSeries/Core.jl`。

#### 处理流程

**1. 传感器选择 (`find_nearest_height_sensor`)**

**功能说明**：
该函数用于在测风塔的传感器列表中查找距离目标轮毂高度最近的匹配传感器。

**选择逻辑**：
- 筛选指定类型 (`WindSpeed` 或 `WindDirection`) 和统计类型 (`avg`) 的传感器
- 计算每个传感器与目标高度的绝对高度差
- 返回高度差最小的传感器
- 如果没有匹配的传感器，返回 `nothing` 并跳过该高度

**2. 数据提取与格式化**

**功能说明**：
从完整时间序列数据中提取匹配传感器对应的数据列，并按照 WT 软件要求的格式进行整理。

**处理步骤**：
- 从输入时间序列中提取时间戳列
- 提取最近匹配传感器的风速数据列
- 提取最近匹配传感器的风向数据列
- 将三列数据整合为标准输出格式
- 将时间戳格式化为 `yyyy-mm-dd HH:MM:ss` 标准格式

**3. 文件输出**

**功能说明**：
将处理完成的时间序列数据保存为 CSV 格式文件，文件名遵循约定的命名规则。

**文件命名规则**：
- 格式：`{测风塔名称}-{高度值}m.csv`
- 高度中的小数点替换为下划线（例如：`120.0m` → `120_0m`）
- 文件保存至配置的输出目录

#### 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 统计类型 | "avg" | 仅使用平均值传感器 |
| 时间格式 | "yyyy-mm-dd HH:MM:ss" | 标准时间戳格式 |
| 文件格式 | CSV | 标准CSV格式 |
| 小数处理 | "_" | 高度小数点替换为下划线 |

## 配置示例

```toml
[[masts]]
name = "TGL1"
input = { data = "./representative-year/TGL1.parquet", sensors = "./representative-year/TGL1.sensors.toml" }
output_dir = "./wt-timeseries"
target_heights = [90.0, 120.0, 140.0]
```

## 默认推荐值

### 目标高度选择
- **常规机组**: 90-120m（根据当前主流机型）
- **大叶片机组**: 140-160m（适用于低风速区域）
- **海上机组**: 100-150m（考虑塔筒高度限制）

### 数据要求
- **输入数据**: 必须经过 representative-year 校准的数据
- **传感器覆盖**: 目标高度应在测风塔传感器高度范围内或接近最高传感器
- **数据完整性**: 输入数据应无大量缺失值

### 输出使用
- **Meteodyn WT**: 直接导入进行流场计算
- **载荷计算**: 作为湍流风输入
- **发电量估算**: 结合功率曲线进行产能评估

## 注意事项

### 数据质量

确保输入的代表性年数据已经过完整的数据清理和校准流程。原始数据中的缺失值、异常值和仪器故障应在前期处理阶段解决。

### 高度覆盖

如果目标轮毂高度远高于测风塔最高传感器高度，提取的数据可能无法完全反映高空的实际风况。建议结合中尺度数据或长期趋势分析进行补充评估。

### 传感器配置

测风塔应配置足够高度范围的风速和风向传感器，以确保在各种目标高度下都能找到合适的匹配传感器。
